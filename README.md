## 🏢 About Nazeen Welfare Foundation

Nazeen Welfare Foundation is a registered nonprofit organization based in **North West Delhi**, working to empower communities through education, skill development, health awareness, and social welfare initiatives.

The foundation aims to create equal opportunities and improve the quality of life for underprivileged communities.

## 🎯 Key Programs

### 1. Local Self Governance & Institutions Building

Empowering communities to participate in decision-making, local governance, and resource management at the grassroots level.

### 2. Education Programmes

Promoting access to quality education and learning opportunities for children, especially those from underprivileged backgrounds.

### 3. Health, Hygiene & Nutrition

Creating awareness about health, hygiene, nutrition, and healthy living practices among communities and families.

## 🎯 Mission

To uplift underprivileged communities by providing access to quality education, promoting women's empowerment, and improving health and social welfare.

## 👁️ Vision

To build a society where every individual, regardless of background, has the opportunity to learn, grow, and live a dignified life.

## 🚀 Run Locally

### 1. Clone the repository

```bash
git clone https://github.com/nazeenwelfarefoundation99/nazeenwelfarefoundation.git
```

### 2. Open the project

```bash
cd nazeenwelfarefoundation
```

### 3. Run the website

You can simply open:

```text
index.html
```

in your browser.

Alternatively, use a local development server:

```bash
python3 -m http.server 8000
```

Then open:

```text
http://localhost:8000
```
